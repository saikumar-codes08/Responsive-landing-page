🌍 Travel Nest

📖 About the Project

Travel Nest is a responsive travel website developed using **HTML, CSS, and JavaScript**. 
It provides users with an interactive platform to explore popular destinations, search for travel locations, 
view package details, and book trips easily. The project focuses on delivering a simple, attractive, and user-friendly travel experience.



🎯 Project Scope

The scope of this project includes:

- Displaying popular travel destinations.
- Searching cities using the Wikipedia API.
- Filtering destinations by category.
- Showing travel package details dynamically.
- Booking trips through an interactive booking form.
- Displaying booking confirmation with a unique Booking ID.
- Providing a responsive interface for desktop and mobile devices.
